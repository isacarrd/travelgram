# Travelgram ✈️📸

Um mini-projeto prático focado em dominar o **CSS Flexbox**. O Travelgram é uma página web estática que simula a interface de um perfil do Instagram, contendo foto de perfil, nome, descrição e uma grade de fotos no feed.

🔗 **Site:** [isacarrd/travelgram](https://travelgram-livid.vercel.app/)

## 🎯 Objetivo e Aprendizado

O principal intuito deste projeto foi colocar o **FLEXBOX na prática** e testar minhas habilidades de layout estrutural. 

Durante o desenvolvimento, adotei a seguinte abordagem:
* Observação atenta do layout proposto no **Figma**.
* Desenvolvimento de uma "lógica própria" para a construção semântica e estrutural do HTML.
* Utilização do Figma como base para extrair e aplicar uma estilização CSS precisa, garantindo que o Flexbox funcionasse perfeitamente para alinhar e distribuir os elementos da página (como o cabeçalho do perfil e o feed de imagens).

## 🚀 Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **CSS3** (Foco principal em `display: flex`)
